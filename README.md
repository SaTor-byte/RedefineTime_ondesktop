# RedefineTime 桌面收入便签

没得干鼓捣的一个基于 Electron、React、TypeScript 和 Vite 的 Windows 桌面收入便签。

可以显示正常工作时的收入、离席收益和加班扣减，并支持跨午夜工作时间、06:00 业务日刷新、主题切换、心情文案和工作日/休息日页面。

## 功能

- Windows 10/11 桌面应用
- 便签窗口置于普通窗口底层
- 支持窗口位置和大小调整
- 支持锁定窗口位置和大小
- 显示正常工作收入
- 显示离席收益
- 显示加班扣减
- 支持跨午夜工作时间
- 支持中国法定节假日和调休
- 支持手动调整日期安排
- 支持多套主题和本地图片主题
- 支持心情文案新增、编辑和删除
- 支持工作日下班确认和休息页面
- 支持提前加班和非工作日加班

## 环境要求

- Windows 10 或 Windows 11
- Node.js 18 或更高版本
- npm
- Git
